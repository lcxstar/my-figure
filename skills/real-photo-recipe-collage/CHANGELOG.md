# Change log

## v2.6 · 2026-11-02

- 封面新图默认 `mask.mode=auto_plate`，每张原片独立识别白色盘/碗外沿，先做椭圆拟合定位，不把手、食物重心或原片中心作为盘/碗定位依据。
- 去手只移除真实前景蒙版之外的像素，不补画被手遮挡的盘沿与菜品。
- 低置信度、外沿不完整或没有盘/碗时明确失败，改为人工审定的 alpha_file 蒙版；严禁重用旧照片坐标。
- 新增 `_QA_rim_preview.png` 原片轮廓与中心标注，保留 `_QA.json` 的原片 SHA256、置信度和居中参数；新图仍需目视验收。
- 封面依然为 3:4、浅灰植物纹桌布、轻度保真调色；六联图算法不变。
- 新增 synthetic tests，检测手臂不参与盘碗定位、正常居中、找不到盘碗时报错、圆盘超出边框时报错。

## v2.5 · 2026-11-02

- 将“制作封面图”替换为基于原片真实像素的居中保真流程：按盘碗真实蒙版 bbox 定位画布中央，尺寸可配置，输出中心偏差 QA。
- 默认更浅的灰色 #D0D0CB 布纹背景，搭配微弱植物印花；支持使用真实拍摄的桌布照片替换模拟纹理。
- 默认轻度调色（亮度1.035、对比1.035、饱和度1.045、锐度1.035）与轻微背景接触阴影，严格保留原有食物与餐具像素。
- 封面脚本、配置模板、README 和自动回归测试同步更新；v2.2 六联图脚本不变。
- 旧版纯色背景设置仍兼容，新照片必须人工检查蒙版、盘沿及去手效果。

## v2.4 · 2026-11-01

- 新增封面图功能（cover_photo.py），以原片真实像素抠图、等比例居中、统一浅灰背景 #C8C8C3、轻度调色。
- 新增 examples/cover.config.template.json、tests/test_cover_photo.py。
- 禁止生成式重绘食物、盘子、碗、锅、缺失盘沿或装饰。手遮挡盘沿时不做凭空补画。
- 输出原片 SHA256 与 _QA.json，初始 review_required。
- 保留原 v2.2 六联图算法和文字排版不动。
