# 封面成图与验收规范 v3.8｜所有封面模式强制

## 适用范围与最高优先级

本规范对 `hybrid_natural_cover`（默认 AI 辅助的自然摄影融合）和 `strict_original_cover`（传统原片像素合成）**同样有效**。与 v2.6–v3.7 的旧尺寸/构图描述冲突时，**本文件优先**。六联图独立执行 `recipe_collage.py` 1500×2000 的原图流程，不受封面编辑流程影响。

## 1. 比例、文件格式与默认尺寸：硬门槛

- **最终封面必须精确为宽:高 = 3:4 的竖版 PNG**，不是“看起来差不多”，也不是 4:5、1:1、9:16。
- 默认像素大小 **1200×1600**；确需更高分辨率，可用 **1500×2000、1800×2400** 等严格等比尺寸。处理时必须在导出后**重新打开实际成品文件读取像素尺寸**，检查 `width * 4 == height * 3`，同时检查 PNG 格式；不能只检查生成指令或画布配置。
- 一旦比例、PNG 格式未通过，立即标记 `fail`，**不能发布为 Skill 合格成品**。不得为了“赶快符合比例”而拉伸盘子、食物或画面。
- 如原生成图比例错误，优先用具备场景理解的图像编辑方式**向外扩展相同质感的真实布纹/原场景背景**至 3:4，原食物与盘/碗保持几何比例不变；必要时安全缩放完整主体并重新融合接触阴影。不得裁掉盘沿/锅沿，不得用纯色硬拼或把成品整体拉伸。修复后对**新 PNG 再次验收**。
- 纯 Python 校验器 `cover_qa.py` **只检测/记录，不自动扩图或重新绘制菜品**。扩图需真实图像编辑并人工目视确认接缝自然。

## 2. 主体完整和紧凑构图

- 首先检查整个盘/碗外缘 360° 全部显示，四边不得触画布边缘、残缺、出现第二层假盘沿或被新背景吃掉。
- **平盘建议占画面宽度 88%–92%，碗约 88%–93%**；优先左右各约 **3%–6%** 空间，顶部和底部可根据透视适当变化，通常至少约 4%。数字是构图目标，不能为了达标硬裁盘沿。
- 能提供**与最终图片同尺寸**、经过确认的主体蒙版时，`cover_qa.py --subject-mask` 根据蒙版 bounding box 计算上下左右的实际边距，低于左右 3% 或主体触边即失败，超过建议范围提示重新构图。
- **没有可靠蒙版时，只能目视核验**，不能编造检测结果或伪称程序已经准确发现盘沿。尺寸合规≠盘沿完整。

## 3. 背景自然融合

- 默认背景：**浅灰米色真实织物质感＋柔和自然的淡绿植物枝叶纹理**，与用户偏好的参考图风格一致；不主动添加真实绿植摆件、木板、餐具、文字或水印。
- 必须依据**用户原始照片进行场景编辑**，保留真实食物种类、数量关系、形状、盘碗轮廓及拍摄视角。AI 只限于去手/去杂物、背景扩展、局部衔接、光影协调、被手遮挡的少量盘底必要补全；**不要从零重画一盘看起来相似的菜**。
- 对手托盘照片，不要只抠出盘子后悬浮粘到布纹背景上：要建立可信的布面承托、窄而真实的接触阴影、与主光源方向一致的柔和投影以及布料自然纹理/微小褶皱。
- 盘子、食物、背景需统一**曝光、白平衡、光线方向、环境反射、纹理颗粒**；不能出现高饱和橙色食物配冷灰布纹、纯白发光的盘沿、双盘边或贴纸硬边。

## 4. 调色原则与顺序

1. 读取原图与参考布料，核对主要食材、数量、盘沿、角度。
2. 优先编辑原照片移除手臂/厨房背景，并完成真实布面替换及接触融合。
3. **只对需要的区域适度增亮、微调对比度/饱和度/色温**，使菜更有食欲但仍然是自然手机摄影。保留食物不规则纹理，禁止塑料感、高饱和油亮、过度锐化/HDR。
4. 确认盘沿完整、画面紧凑且背景自然。若原始生成的尺寸错误，只扩展背景并重新检查接触关系。
5. 导出无文字 **3:4 PNG**，重新打开实际图片运行程序 QA，再执行人工视觉审查。**不要拿已完成的封面再次无目的整张 AI 重绘或强滤镜处理**。

注意：封面与六联图是独立模式；六联图仍强制**完整原片先逐张调色 → 裁剪 → 两列三行 → 最后上字**。

## 5. 机器可验证 + 人工目视：不虚报

仓库提供正式 `cover_qa.py`。使用方式：

```bash
cd skills/real-photo-recipe-collage

# 第一遍：只检查实际格式/长宽比例；缺人工检查应为 review_required。
python cover_qa.py --image output/cover.png --source input/original.jpg

# 生成同最终图 SHA256 绑定的视觉验收清单，默认全为 false。
python cover_qa.py --image output/cover.png --source input/original.jpg --init-review

# 仔细目视核对后填写 *_review_template.json 中的全部项目。
# 有可信主体蒙版就传 --subject-mask，否则边距仅能目视核对。
python cover_qa.py --image output/cover.png --source input/original.jpg \
  --review output/cover_review_template.json --strict
```

人工验收清单必须包括：

- `plate_rim_complete`：整个盘/碗外缘完整，未触边、未出框。
- `food_structure_preserved`：食物的种类、形态、数量关系与原片基本相同。
- `no_hand_or_clutter`：手和厨房杂物清理干净。
- `natural_table_contact`：盘底真实贴桌，不浮空，接触与投影方向可信。
- `consistent_light_and_white_balance`：背景与食物白平衡、光线、明暗相协调。
- `natural_color_no_plastic_look`：自然调色、不泛橙、无塑料感。
- `background_appropriate_no_extra_props`：布纹自然且无无故添加的道具。
- `no_destructive_edit_after_final`：导出后没有对整张成图做破坏性滤色或重绘。

**审查文件绑定源照片与最终图片的 SHA256。**任何图片一经重新编辑都必须重新人工验收。没有审查文件、任何检查项未确认、蒙版提示主体边距异常，都不得声称“验收通过”。

## 6. 验收状态

- `fail`：像素比例不精确、文件非 PNG、可信蒙版显示主体越界/左右低于 3%，或复核 SHA 不匹配。不得作为合格封面交付。
- `review_required`：尺寸合格，但缺少完整视觉确认；或主体边距大于推荐范围。可继续修图/核实，不得说已通过 Skill。
- `pass_manual_checked`：机器可确认的检查通过，并且由目视检查人员逐项确认、与当前最终图 SHA256 匹配。**程序无法客观证明食物完全未被 AI 修改、接触阴影一定真实**；该状态表示“机器检查＋明确人工核对”，不等于自动视觉真值。
